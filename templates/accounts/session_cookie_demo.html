Viva & Examination Checklist for INT253 Unit 6
Cookie vs Session
Cookies store small data (≤4KB) directly in client browser headers. Sessions store data securely on the web server (SQLite/Redis); only the random 32-character sessionid is sent to the client.
Django Syntax Reference
request.session['key'] = value
request.session.get('key', default)
response.set_cookie('name', val, max_age)
request.COOKIES.get('name')
Built-in Authentication
Uses authenticate() to verify PBKDF2 password hashes, login() to tie user PK to current session, and the @login_required decorator to protect endpoints.
